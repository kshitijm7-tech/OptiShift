# OptiShift Roadmap

There are EXACTLY 10 phases.

P01 — Project Foundation + Development Contract: Establish the core repository structure, baseline configuration, and agent rules.
P02 — Core Data Models + Backend Foundation: Implement backend schemas, data services, and database mock/connection.
P03 — Optimization Engine: Implement real mathematical optimization logic using PuLP/CBC.
P04 — Frontend Foundation + Core UI: Build React components and adapt the Stitch UI visually.
P05 — Schedule + Dashboard Integration: Connect the frontend schedule view to the backend optimization results.
P06 — Demo Mode + Baseline Comparison: Allow comparison between unoptimized baseline and optimized schedule.
P07 — Leave + Approval + Re-optimization: Handle time off requests and trigger re-optimization.
P08 — Custom Mode + Dynamic Scheduling: Enable custom rules configuration and dynamic solver parameters.
P09 — Testing + Sentinel Verification + Hardening: Perform integration testing and security/stability checks.
P10 — Final Integration + UX Polish + Algothon Demo Gate: Final visual tweaks and readiness for the demo.
